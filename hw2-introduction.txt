M = cumulative_minimum_energy_map(energyImage,seamDirection) - computes minimum cumulative energy. The input energyImage is a 2D matrix output by the energy_image function that you will implement (see below), and the input seamDirection is either 'HORIZONTAL' or 'VERTICAL'. The output is a 2D matrix of class double.
verticalSeam = find_optimal_vertical_seam(M) and horizontalSeam = find_optimal_horizontal_seam(M) - compute the optimal vertical and horizontal seams. The input is the 2D matrix output by cumulative_minimum_energy_map, and the output is a vector containing the row indices (or column indices, respectively) of the pixels belonging to a horizontal (or vertical, respectively) seam. For a horizontal seam, you have as many seam points as you have image columns, i.e. one row index for each image column.
reducedColorImage = reduceHeight(im, display_flag) - reduces the height of your image in a content-aware way. (Use this to implement reduceWidth below)
Functions you need to implement:
[10 pts] [energyImage, Ix, Iy] = energy_image(im, Ix_kernel, Iy_kernel) - to compute the energy at each pixel using the magnitude of the x and y gradients.
In this function, you first need to convert it to grayscale before computing the gradients, using rgb2gray.
Then, you need to change the type of your grayscale image I to double using double(I) function to get negative values after filtering. If you apply your filter on uint8 image, all < 0 values will become 0 (the minimum uint8 value), which is not what you want.
Then apply the filter and compute the energy map.

Inputs:
im should be a nrows-by-ncols-by-3 matrix of class (datatype) uint8, e.g. the output of imread on a color image.
Ix_kernel and Iy_kernel: kernels for Ix and Iy respectively. These are predefined in hw2.m, but you can try other kernels if you want.
Outputs:
Each of the outputs energyImage, Ix, Iy should be 2D matrices of class double, each of size nrows-by-ncols-by-1.
Ix, Iy are the gradients in the x and y directions, i.e. the dI/dx and dI/dy; use the filters we discussed in class to compute them as provided in the script. You are welcome to use imfilter, but don't use Matlab's imgradient function.
energyImage is using L2 norm: sqrt((dI/dx)^2+(dI/dy)^2). In other words, for each energyImage[i,j], compute the L2 norm using the dI/dx and dI/dy values at i,j. This possible without loops (you can use loops though).

[15 pts] reducedColorImage = reduceWidth(im, display_flag) - to reduce the width of your image in a content-aware way. The function should call the energy_image, cumulative_minimum_energy_map, and find_optimal_vertical_seam functions. Note: The provided reduceHeight is the "height version" of reduceWidth. Simply start from reduceHeight and change this to reduceWidth.

Inputs:
The function should take in a nrows-by-ncols-by-3 matrix im of class uint8.
If the display_flag is set to true, the function should display, in a 1x3 subplot, the following: (a) the energy image, (b) the cumulative energy image, (c) the optimal seam (using displaySeam).
Outputs:
The output must be a 3D matrix reducedColorImage, of class uint8, which is the same as the input image but with its width reduced by one pixel.

[10 points] contentAwareResize = generate_results(filename, reduceAmt, reduceWhat) - repeatedly reduce the size by calling appropriate functions and return the reduced image as contentAwareResize. In your function, after reading in the image, you should call reduceWidth or reduceHeight as many times as needed to reduce the width/height by the requested amoun.

Inputs:
filename is a character array (e.g. 'prague.jpg'),
reduceAmt is an integer which says by how many pixels to reduce the width/height, and
reduceWhat is 'WIDTH' or 'HEIGHT'.
Outputs:
contentAwareResize containing the content-aware reduced image.
